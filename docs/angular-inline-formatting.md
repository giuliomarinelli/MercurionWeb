# Formattare HTML e CSS inline nei componenti Angular (VS Code)

Nei file `.ts`, seleziona **solo il contenuto** del `template` o del blocco in `styles`, senza i delimitatori del literal. Con i keybinding globali configurati in VS Code su questa postazione:

| Contenuto selezionato | Scorciatoia | Formatter usato |
| --- | --- | --- |
| HTML del `template` | `Ctrl+Alt+Shift+H` | HTML integrato di VS Code |
| CSS in `styles` | `Ctrl+Alt+Shift+C` | CSS integrato di VS Code |

Le scorciatoie funzionano quando l'editor attivo è un file TypeScript e c'è una selezione. Copiano la selezione negli appunti, la formattano in una nuova scheda senza titolo e incollano il risultato nel file originale. **Sostituiscono il contenuto degli appunti** e lasciano aperta la scheda temporanea.

Questi keybinding sono nella configurazione **utente** di VS Code, non nelle impostazioni condivise del repository: su un'altra postazione vanno configurati separatamente.
