# Deferred task recipes

This directory stores non-executable recipe backups reserved for a separately
scheduled development program. Files here are excluded from the current
autonomous planner and worker dispatch.

Reserved numeric and Source identities remain owned by their Series registry and
must not be reused. A recipe may return to executable work only through a direct
management decision and an explicit future-program configuration; copying a
file into this directory does not create a task outcome or dependency skip.

- `0164 / DATA-015`
- `0165 / DATA-016`
- `0166 / DATA-017`
- `0167 / DATA-018`
